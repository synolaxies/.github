### 🚀 Core Platforms

#### 🌐 Web Platforms
Fast, responsive web applications and digital utilities built with modern web standards and globally deployed via edge infrastructure.

#### 📱 Android Applications
Native Android applications engineered with **Kotlin** and **Jetpack Compose**. Built with clean modular architecture, high-performance local storage, and secure cloud synchronization.

#### 📐 SketchUp Extensions
Custom plugins, workflow automation tools, and productivity extensions for **Trimble SketchUp** using **Ruby**. Designed to streamline architectural modeling, repetitive drafting, and CAD operations.
